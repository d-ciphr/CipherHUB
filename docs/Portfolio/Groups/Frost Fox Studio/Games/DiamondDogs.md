# Diamond Dogs
A military roleplay game based on MGSV that was somewhat recently acquired by Frost Fox Studio.

Has many features that are either upcoming, or complete.<br>
Including but not limited to:

- A completely refactored codebase.
- Completely re-designed UI that matches the Metal Gear V style.
- Reworked AI and Stealth Mechanics.
- A reworked morph system.
- A Haircut System.
- Updated Helicopter System.
- Redone Contracts.
- An overhauled weather system.

You can look at the game [here](https://www.roblox.com/games/6878450616/Northern-Kabul-Afghanistan).
